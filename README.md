# Telegram бот на Python

- Мой первый проект 

## Возможности

- Выдаёт данные о погоде по всему миру

## Требоввания 

- Python 3.14
- Установить соответствующие бибилиотеки

## Установка

- python-dotenv
- httpx
- aiogram >= 3

## Настройка

- Создать папку .env и указать токен в переменную BOT_TOKEN

## Запуск

- python main.py
